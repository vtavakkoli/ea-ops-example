EA-Ops principle
Git handles collaboration and access. EA-Ops handles architecture semantics and governance.

Pull requests become architecture change requests. `main` is the approved architecture. CI validates the model before change is accepted.

Try the same workflow locally.

The example is a normal consumer repository; the framework lives separately.

python -m pip install "git+https://github.com/vtavakkoli/ea-ops.git"

eaops validate .
eaops summary .
eaops impact . --id app.case-management
eaops report . -o architecture-report.md
eaops build . -o site
Metroville is fictional. This reference architecture demonstrates EA-Ops and does not represent any real municipality or production environment.
